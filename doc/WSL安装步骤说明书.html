WSL（Windows Subsystem for Linux）离线安装步骤说明书

适用环境：Windows 10 1903+ / Windows 11。本说明基于离线安装包方式，全程不依赖微软在线下载（官方在线安装慢/失败的根因是发行版清单托管在 raw.githubusercontent.com，国内访问受限）。

安装包清单（本目录）

文件大小用途
wsl-installer.msi247 MBWSL 本体 2.7.12.0（含 wsl.exe、内核、服务）
ubuntu-22.04-wsl.rootfs.tar.gz325 MBUbuntu 22.04.5 LTS 根文件系统（清华镜像）
重要：第 1、2 步需要管理员权限（弹 UAC 点"是"）；第 2 步后需要重启电脑一次。

步骤一：启用 Windows 功能（管理员）

打开管理员 PowerShell / CMD（开始菜单搜索 PowerShell → 右键 → 以管理员身份运行），执行：

dism /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

两条都显示"操作成功完成"后，重启电脑。

步骤二：安装 WSL 本体（管理员）

msiexec /i "E:\software\wls\wsl-installer.msi" /qn /norestart

静默安装，约 10 秒。验证：

wsl --version

输出类似 WSL 版本: 2.7.12.0 即成功。

提示：若提示需要 WSL2 内核，本 MSI 已内置最新内核（6.18.x），无需再单独安装旧版 wsl2kernel 更新包。

步骤三：导入 Ubuntu 发行版（免管理员）

普通 PowerShell 执行（导入目标盘符和目录可自定义，建议放非系统盘）：

mkdir D:\WSL\Ubuntu
wsl --import Ubuntu D:\WSL\Ubuntu "E:\software\wls\ubuntu-22.04-wsl.rootfs.tar.gz"

验证：

wsl -l -v

应显示 Ubuntu Stopped 2。

步骤四：首次进入并初始化

wsl -d Ubuntu

以 root 身份进入（--import 方式默认 root）。设置默认用户与密码：

passwd root

（可选）创建普通用户：

adduser yourname

步骤五：更换 apt 国内源并安装开发工具

sed -i 's/archive.ubuntu.com/mirrors.tuna.tsinghua.edu.cn/g; s/security.ubuntu.com/mirrors.tuna.tsinghua.edu.cn/g' /etc/apt/sources.list
apt-get update
apt-get install -y gcc g++ make build-essential

验证编译器：

gcc --version    # 应显示 gcc 11.4.0

安装包完整性校验（可选）

安装前建议校验 MSI 完整性（本机曾因镜像下载截断损坏报错 1620）：

python -c "import msilib; msilib.OpenDatabase(r'E:\software\wls\wsl-installer.msi', msilib.MSIDBOPEN_READONLY); print('OK')"

rootfs 校验（下载源 MD5）：

CertUtil -hashfile "E:\software\wls\ubuntu-22.04-wsl.rootfs.tar.gz" MD5

常见问题

现象原因与解决
msiexec 返回 1620MSI 文件损坏（下载截断）。重新完整下载并校验
wsl --install 报 0x80070005未用管理员权限，或功能未启用（先做步骤一）
wsl --install -d Ubuntu 卡住/超时发行版清单在 GitHub raw，被墙。用本说明的 rootfs 导入法
WSL 命令提示"未安装分发"本体装好但没导入发行版（做步骤三）
导入后 rootfs 解压慢正常，325MB 压缩包解压约 1-2 分钟，放 SSD 更快
备选发行版：需要其它版本可去清华镜像列目录找（如 noble=24.04、oracular），URL 结构：
https://mirrors.tuna.tsinghua.edu.cn/ubuntu-cloud-images/wsl/<版本>/current/，文件名带 -ubuntu<版本号>lts 后缀，务必先列目录确认。
