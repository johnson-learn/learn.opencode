Windows 下使用 WSL（Linux）编译与运行 C 代码说明书

适用环境：已按《WSL 安装步骤说明书》完成 WSL + Ubuntu 22.04 + gcc 安装。本机发行版名为 Ubuntu，装在 E:\WSL\Ubuntu。

一、常用 WSL 命令速查

命令（Windows PowerShell 中执行）作用
wsl -l -v列出所有发行版及状态/版本
wsl -d Ubuntu进入 Ubuntu 交互式 shell
wsl -d Ubuntu -e bash -c "命令"不进入 shell，直接执行一条 Linux 命令
wsl --shutdown关闭 WSL（释放内存）
wsl --set-default Ubuntu设为默认发行版
wsl --set-version Ubuntu 2切到 WSL2 内核

二、文件互通（Windows ⇄ Linux）

Windows 盘符在 Linux 中挂载为 /mnt/<盘符小写>：

Windows 路径Linux 路径
E:\openCodeDefault\temp\main.c/mnt/e/openCodeDefault/temp/main.c
C:\Users\你的用户名/mnt/c/Users/你的用户名

Windows 资源管理器地址栏输入 \\wsl$\Ubuntu\ 可浏览 Linux 文件系统。

注意：编译建议在 /mnt/e/...（Windows 盘）直接进行，产物两边都能访问；但大型构建（大量小文件 IO）在 /mnt 下会慢，此时可把源码复制到 Linux 家目录 ~/ 编译。

三、编译并运行 C 代码（三步走）

3.1 单文件程序

# Windows PowerShell 中，一条命令完成编译+运行（E 盘路径示例）
wsl -d Ubuntu -e bash -c "cd /mnt/e/openCodeDefault/temp && gcc -O2 -pthread main.c -o main && ./main"

分步写法（进入 Linux 后）：

wsl -d Ubuntu                    # 进入 Linux
cd /mnt/e/openCodeDefault/temp   # 切到源码目录
gcc -O2 main.c -o main           # 编译
./main                           # 运行

3.2 多线程程序

必须加 -pthread（GCC 才会链接 POSIX 线程库）：

gcc -O2 -pthread linux_thread_demo.c -o demo
./demo 2000          # 参数可传节拍数

3.3 常用编译选项

选项含义
-O2二级优化（推荐默认）
-g加调试符号（配合 gdb）
-Wall -Wextra打开常见警告
-pthread多线程必加
-lm链接数学库（用了 math.h 时）
-std=c11 / -std=c17指定 C 标准

五、验证过的示例：0.5ms 实时线程框架

源码：E:\openCodeDefault\temp\linux_thread_demo.c（主进程 + 双线程 + 0.5ms 节拍驱动 + 计数回报）。

wsl -d Ubuntu -e bash -c "cd /mnt/e/openCodeDefault/temp && gcc -O2 -pthread linux_thread_demo.c -o demo && ./demo 2000"

实测输出（2000 拍 = 精确 1.0 秒，Linux 上 0.5ms 粒度完全达成）：

[主进程] 启动时间戳: 2026-08-21 15:50:28.478807
[主进程] 结束时间戳: 2026-08-21 15:50:29.478679
[主进程] 线程1 计数: 2000 (期望 2000)
[主进程] 线程2 计数: 2000 (期望 2000)
[主进程] 计数一致: 是

七、常见问题

现象解决
undefined reference to 'pthread_create'编译没加 -pthread
程序在 /mnt 下运行很慢复制到 Linux 家目录 ~/ 再跑（/mnt 是 9P 网络盘，小文件 IO 慢）
中文输出乱码源码保存为 UTF-8；终端设置 UTF-8：chcp 65001（Windows 侧）
WSL 内存占用大wsl --shutdown 释放；或 .wslconfig 限制内存
想换 Ubuntu 版本重新 wsl --import 其它 rootfs（见安装说明书备选发行版）
Windows 侧直接编译（无 WSL 时）用 w64devkit 便携 GCC（winpthreads），但 0.5ms 级实时精度只有 Linux 能做到
核心结论：日常 C 开发用 wsl -d Ubuntu -e bash -c "cd /mnt/e/... && gcc ... && ./..." 一条命令搞定；需要精确到亚毫秒的实时程序，必须在 WSL/Linux 上编译运行（Windows 定时器精度极限约 1ms）。
