# find_skill 参考：检索策略（关键词拆解/多源交叉/可信度分级/反模式）

## 1. 任务 → 检索计划

1. 拆解问题为 2~5 个关键词组合（同义词/中英文/缩写各一组）
2. 确定来源优先级：官方权威源 > 一手资料 > 二手综述 > 论坛/问答
3. 每个关键结论至少两个独立来源交叉验证

## 2. 可信度分级

| 级别 | 来源 | 用法 |
|---|---|---|
| S 权威 | 官方规范/论文原文/厂商文档 | 直接引用，标注出处 |
| A 一手 | 源码/实测/数据库记录 | 作为主要依据 |
| B 二手 | 高质量综述/百科/技术博客 | 佐证，关键处回溯 A/S 级 |
| C 低可信 | 论坛/问答/AI 生成内容 | 仅线索，禁止作为结论依据 |

## 3. 反模式（禁止）

- 单源下结论（任何关键结论必须 ≥2 独立来源）
- 只搜中文/只搜英文（两者都要，缩写术语以英文为主）
- 镜像渠道一次失败即放弃（按渠道表逐个尝试，每渠道失败换下一个）
- 把 AI 生成内容当事实（必须回溯到 S/A 级原始出处）

## 4. 证据表模板（深度研究必用）

| # | 结论/事实 | 来源 URL | 级别 | 备注 |
|---|---|---|---|---|
| 1 | ... | ... | S/A/B | ... |

## 5. 常用入口优先级

- 规范/标准：3GPP FTP / ETSI / arXiv（见 SKILL.md 站点表）
- 代码仓库：GitHub → 直连失败走 ghproxy.net tarball
- skill 搜索：skillsmp.com（SSR 免登录）→ skills.sh sitemap → LobeHub CLI
