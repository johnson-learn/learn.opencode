# 六步固化输出模板（evolution_skill templates）

> 每次执行固化时，按本模板填空输出；六个标记行顺序固定（gate --check-5step 程序化检测，参数名保留历史名）。

```
【第一步·归纳】
{经验描述}（一两句精确表述，按可移植性要求通用化，无本机路径）
{经验类型}：规则（进可执行载体）| 记录（仅流水）
{触发场景}：何时适用

【判定四条件】场景数：X / 可移植：是 / 无重复：是 / 边界：明确
（任一不满足 → 仅追加 evolution_log.txt 事实类，不进规则文件、不弹窗）

【第二步·归属】
{主载体}：对应 SKILL.md / instructions.md / regedit.md / AGENTS.md / evolution.md
{配套同步文件}：按 docs-sync.md 映射表列出
{校验测试}：test_regedit / test_instructions / skill_validate / 行为实测

【第三步·确认】
{用户选择}：同意 | 跳过 | 填写内容（用户填写：{原文}）
（question 工具弹窗逐条选择；用户未确认前不得 edit 任何进化相关文件）

【第四步·edit】
{逐个 edit 目标文件清单与改动摘要}（每个 edit 后自检：有无误删无关内容）

【第五步·流水】
{evolution_log.txt 追加结构化条目：状态/场景数/最后验证/核心关键词/归属/载体/内容}

【第六步·校验】
{内容核查：命令可执行/无硬编码路径/标注验证状态}
{结构化自测：skill_validate.py}
{行为实测：涉及命令实跑结果 | 未实测待验证清单}
```

响应末尾附：`进化：已固化 …`（或 `进化：无新固化` / `进化：用户跳过 N 条`）
