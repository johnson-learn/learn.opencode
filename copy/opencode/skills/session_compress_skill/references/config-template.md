# 会话压缩模板（config-template）—— session_compress_skill 的权威模板

> 本文件是 `session_compress_skill` 生成 `session.md` 的**唯一权威**模板。
> 用途：长会话"过程折叠成状态"——在里程碑把多轮业务上下文压缩成 `session.md`，然后**开新会话**由用户手动继承，避免输入 token 随历史线性膨胀。
> 生成：会话过长时触发 `session_compress_skill：`，按本模板结构写入工作目录下的 `session.md`。
> 属会话工作产物，非框架；可删可迁移。

## 标准结构（生成 session.md 时套用）

````markdown
# 说明：以下内容是上一个会话压缩后的历史上下文，为了避免输入 token 过大，新会话继承以下内容继续历史主题对话

## A. 历史会话主题
- <一句话主题，如 "NR PDCCH 配置链梳理">
- 【用户核心目标】<本次会话用户真正要达成的目标，如 "吃透 PDCCH 监听机制并产出可直接复用的详版参考文档"；让新会话先懂"为什么做"再懂"做了什么">

## B. 历史会话目录
- 工作目录：`<绝对路径>`
- 资料目录：`<绝对路径，放参考文档/协议/语料>`
- 文件输出目录：`<绝对路径，放 HTML/产物>`

## C. 历史会话要点
- 【任务状态】<续作必需的最小状态，如"已生成详版Word初版+修订版，修订版补R13~R17"；只写"做到哪一步"，不写细节结论>
- 【领域结论】<已核实的要点，但只收"新会话若继续深挖本主题最少需要的核心结论"；凡细节/大块内容已落在 D 文件产物里的，这里只写一句"详见 D 的 <文件>"指引，不重复全量复制>
- 【业务经验/已踩坑】(可选) <只记业务类的踩坑及解决，以"问题→解决"一句话记，如"§10.1 尾部 R13~R17 曾被遗漏、已补齐；交叉引用编号曾不一致已统一"；帮助新会话避免重蹈；**不含框架 skill 的踩坑**>

## D. 历史会话修改/输出文件
- `<输出文件1>` ← 说明
  【关键内容指向】<该产物里最重要的结论/结构在哪个位置、新会话要看哪节，如"修订版 docx 第三部分藏 §10.1 全部规则 R1~R17、第四部分§12、第五部分§13，交叉对比在第六部分"——对齐 Claude 摘要的'文件+代码片段'保留，让新会话决定要不要打开、打开看哪节>
- `<输出文件2>` ← 说明
  【关键内容指向】<...>

## E. 历史会话使用工具
- 工具1：<只列非内置业务工具名>
- 复用资源：<本任务可复用的脚本/中间产物路径及一句话用途，便于新会话直接复用而非重做>
````

## 使用规则

1. **只写业务类**：A 主题 / B 目录 / C 要点 / D 改输出文件 / E 工具——**全部为业务类内容**（本任务相关）。
2. **上下文不包括框架 skill**：框架 skill 的**讨论、修改、工具、进化**一律不写入 session.md。
3. **C 要点分三层**：**【任务状态】**=续作必需的最小状态（做到哪一步、文件在哪），必须写；**【领域结论】**=只收"已核实 + 已落地 + 用户确认"的核心结论，凡细节/大块内容已落在 D 文件产物里的只写一句"详见 D 的 <文件>"指引，不重复全量复制；**【业务经验/已踩坑】**=可选，只记业务类的"问题→解决"（帮助新会话避免重蹈），禁止记录框架 skill 的踩坑/讨论。禁止未验证推测；不含框架 skill 讨论。
4. **D 文件**：列本次会话产生/修改的**业务输出文件**（HTML、md 等任务产物），**不列框架 skill 的改动文件**；每个文件条目下用**【关键内容指向】**说明该产物最重要的结论/结构在哪、新会话要看哪节（对齐 Claude 摘要的"文件+代码片段"保留）。

5. **E 工具分两块**：只列实际使用过的业务工具名，不写操作步骤/方法；框架运营类工具（health_check、skill_validate 等）不写；**opencode 内置工具不写**。另含**【复用资源】**：本任务可复用的脚本/中间产物路径 + 一句话用途，便于新会话直接复用而非重做。
6. **不写"下一步"**：交给新会话由用户按新需求提出，避免绑架新方向。
7. **继承方式**：新会话开头由**用户手动**粘贴本摘要全文（或引用文件），即可从业务结论继续，无需重读旧会话历史。

## 文件命名与位置

- 文件名固定：**`session.md`**
- 位置：当前任务的工作目录（提问所在目录）
- 覆盖规则：覆盖工作目录下已有的旧版 `session.md`
